A lightweight, browser-based interactive quiz app built with vanilla JavaScript — no frameworks, no dependencies.

---

## 🚀 Live Demo

Simply open `index.html` in any browser — no server required.

---

## 🛠️ Tech Stack

- **HTML5** — Structure
- **CSS3** — Styling and layout
- **Vanilla JavaScript** — Quiz logic, scoring, and results

---

## 📁 Files

```
relationship-quiz/
├── index.html    # Main page
├── script.js     # Quiz logic and scoring
└── style.css     # Styling
```

---

## ▶️ How to Run

```bash
git clone https://github.com/Rakkao-hub/relationship-quiz.git
cd relationship-quiz
open index.html   # or double-click the file
```
